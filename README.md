# Personal Portfolio Website

Welcome to my personal portfolio! This website showcases my profile, technical skills, projects, achievements, and learning journey as a BTech Artificial Intelligence and Machine Learning student.

## About the Project

This is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. It is designed to present my academic background, technical interests, and projects in a professional way.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Interactive functionality

## Features

- Personal introduction and profile
- Education and skills sections
- Projects and certifications sections
- Dark and light mode toggle
- Interactive five-question JavaScript quiz
- Quiz score and answer feedback
- Responsive website design

## Project Files

- `index.html` – Main portfolio webpage
- `style.css` – Website styling
- `script.js` – Theme toggle functionality
- `quiz.html` – Quiz webpage
- `quiz.js` – Quiz functionality
